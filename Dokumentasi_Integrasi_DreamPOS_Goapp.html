1. Ringkasan Eksekutif & Arsitektur Solusi

Dokumentasi ini disusun untuk memandu tim engineering dalam membangun, menguji, dan memelihara jembatan integrasi antara sistem Point of Sale (DreamPOS) dengan sistem Customer Relationship Management (Goapp CRM).

Untuk memastikan kode bersih, modular, dan mudah di-embed ke dalam sistem utama DreamPOS yang sudah ada, arsitektur dibangun menggunakan Multi-Project dalam 1 Solution:

  1. DreamposXGoapp (.dll): Class Library independen yang bertindak sebagai modul SDK/Driver integrasi. Seluruh logika protokol HTTP, token auth caching, auto-retry voucher, manajemen point balance, dan pembuatan format struk berada di sini. Modul ini tidak memiliki dependensi antarmuka (UI-free), sehingga siap di-reference oleh aplikasi POS kasir mana pun.
  2. TryDreamposXGoapp (.exe): Aplikasi Windows Forms desktop yang berfungsi sebagai Test Harness (alat uji coba visual-manual). Pengembang dan tim QA dapat menguji setiap fungsi (Cek Member, Potong Poin, Validasi Voucher, Push Transaksi, Cetak Struk) secara terisolasi tanpa perlu menjalankan keseluruhan sistem POS utama.
Hasil Verifikasi Kredensial Langsung ke Server Goapp:
Autentikasi dengan kredensial API Key 138350315235400 telah diverifikasi aktif dan terhubung ke Channel "Dream POS" (Offline Channel) di server produksi Goapp.

2.3 Catatan Penting Target Framework (.NET Framework 4.7.2)

Rasional Pemilihan Target Framework:
Project awalnya dibuat dengan .NET Framework 4.0. Namun, API Goapp menggunakan protokol HTTPS modern dengan enkripsi TLS 1.2 serta membutuhkan pemanggilan non-blocking via Async / Await dan HttpClient. Mengupgrade target ke .NET Framework 4.7.2 (atau 4.8) memberikan dukungan native TLS 1.2 out-of-the-box tanpa dependensi eksternal yang rentan konflik (*DLL Hell*).

4.6 Mekanisme Auto-Retry Menggunakan Voucher

Untuk melindungi transaksi kasir dari kendala koneksi internet yang tidak stabil (micro-drop), fungsi UseVoucherWithRetryAsync pada DLL menerapkan algoritma cerdas:

  • Error 400 (Bad Request): Berarti voucher memang tidak valid, kedaluwarsa, atau sudah terpakai. Sistem langsung berhenti dan tidak melakukan retry.
  • Error Jaringan / Timeout / 5xx Server Busy: Sistem otomatis mencoba ulang hingga 3 kali dengan jeda waktu bertingkat (Exponential Backoff: 1.5 detik → 3.0 detik).

5. Panduan Pengujian Form Test Harness (TryDreamposXGoapp)

Aplikasi pengujian TryDreamposXGoapp.exe dirancang untuk memvalidasi seluruh fungsionalitas secara visual sebelum DLL diintegrasikan ke sistem POS produksi.

5.1 Contoh Pemanggilan DLL untuk Registrasi Member Baru (VB.NET)

Berikut adalah contoh kode VB.NET untuk memanggil fungsi RegisterMemberAsync dari Class Library DreamposXGoapp.dll:

''' <summary>
''' Mendaftarkan member baru langsung dari kasir POS ke Goapp CRM secara Async/Await
''' </summary>
Private Async Function DaftarkanMemberBaruAsync() As Task
    Dim firstName As String = "Budi"
    Dim lastName As String = "Santoso"
    Dim mobileNo As String = "081298765432"
    Dim email As String = "budi@gmail.com" ' Opsional, boleh Nothing
    Dim schemeUid As Long = 138348545946696
    Dim schemeName As String = "Go Member"

    Try
        ' 1. Panggil method RegisterMemberAsync dari objek GoappApiClient DLL
        Dim resp As ApiResponse(Of MemberResponse) = Await _client.RegisterMemberAsync(
            firstName:=firstName,
            lastName:=lastName,
            mobileNo:=mobileNo,
            email:=email,
            schemeUid:=schemeUid,
            schemeName:=schemeName
        )

        ' 2. Periksa status keberhasilan
        If resp.IsSuccess AndAlso resp.Data IsNot Nothing Then
            Dim member = resp.Data
            MessageBox.Show(
                $"Member berhasil didaftarkan!{Environment.NewLine}" &
                $"Nama: {member.FullName}{Environment.NewLine}" &
                $"UID Goapp: {member.Uid}{Environment.NewLine}" &
                $"No HP: {member.MobileNo}",
                "Sukses", MessageBoxButtons.OK, MessageBoxIcon.Information)
            
            ' 3. Lanjutkan transaksi POS dengan UID member baru tersebut
        Else
            MessageBox.Show($"Pendaftaran gagal: {resp.Message}", "Gagal", MessageBoxButtons.OK, MessageBoxIcon.Error)
        End If

    Catch ex As Exception
        MessageBox.Show($"Error Exception: {ex.Message}", "Error", MessageBoxButtons.OK, MessageBoxIcon.Error)
    End Try
End Function

Private Async Sub btnSearchMember_Click(sender As Object, e As EventArgs) Handles btnSearchMember.Click
    Dim queryInput = txtInputMember.Text.Trim()
    If String.IsNullOrEmpty(queryInput) Then Return

    ' Disable tombol sementara agar kasir tidak melakukan double-click

1. Uji Autentikasi Buka TryDreamposXGoapp.exe, klik Test Koneksi. Label hijau: Terkoneksi: Dream POS (offline), UID: 138350315235400. PASSED (Verified)
2. Cek Member (HP) Buka Tab 1, masukkan nomor HP member aktif, klik Cek Member. Nama, Tier Level, Sisa Poin, dan Nilai Rupiah tampil akurat. Siap Diuji di Form
3. Cek Member (ID) Buka Tab 1, masukkan UID Member (angka), klik Cek Member. Respon sama persis dengan pencarian nomor HP. Siap Diuji di Form
4. Validasi Voucher Buka Tab 2, ketik kode voucher, klik 1. Validasi Voucher. Tampil status valid/tidaknya voucher beserta deskripsi promo. Siap Diuji di Form
5. Pakai Voucher Ketik kode voucher dan nomor nota POS, klik 2. Gunakan Voucher. Voucher terkunci ke transaksi. Auto-retry berjalan jika koneksi terganggu. Siap Diuji di Form
6. Burn Point Buka Tab 3, masukkan jumlah poin yang akan dibakar, klik Burn Point. Muncul PaymentRef, saldo poin member langsung berkurang. Siap Diuji di Form
7. Void Poin Klik tombol Cancel Burn Point (Void). Status transaksi poin menjadi CANCEL, saldo poin konsumen kembali pulih. Siap Diuji di Form
8. Earning Point Buka Tab 3, klik Push Transaksi Selesai. Order terkirim ke Goapp, tampil jumlah penambahan poin baru (Reward). Siap Diuji di Form
9. Preview Struk Buka Tab 4, klik Generate Preview Struk. Teks struk 40 kolom tercetak lengkap dengan saldo poin dan URL survey QR. Siap Diuji di Form
10. Daftar Member Baru Tab 5: Isi Nama & No HP baru, klik Simpan / Daftarkan Member. Member tersimpan di Goapp (HTTP 201 Created), redirect otomatis ke Tab 1 & saldo awal tampil. PASSED (Verified)
11. Cancel Voucher (Void) Tab 2: Isi kode voucher & nomor nota yang sudah dipakai, klik 3. Batalkan Voucher (Void). Voucher kembali ke status available. API: {"detail": "Deal code cancelled successfully."} Siap Diuji di Form
12. Load Daftar Promo Tab 6 Panel Kanan: Klik Load Daftar Promo Aktif. Listbox terisi daftar deal aktif dari GET /member/deal/ beserta UID, nama, SKU. Siap Diuji di Form
13. Void Deal Code (Tab 6) Tab 6 Panel Kanan: Pilih deal, isi Kode + Nota + UID Member, klik Submit Void Kode Voucher. Kode di-void via POST /member/deal/cancel_code/. Status kembali available. Siap Diuji di Form
14. Insert Master Voucher Tab 6 Panel Kiri: Isi Nama, SKU, Tipe, Nilai, Tanggal, klik Insert Voucher Baru. Promo baru terbuat di Goapp CRM (HTTP 201). SKU tidak valid = pesan informatif ditampilkan. Siap Diuji di Form
